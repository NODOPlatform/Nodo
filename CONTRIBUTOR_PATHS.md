# Caminos de Contribucion — NODO

Elige el camino que mejor se adapte a tu perfil.

---

## Frontend

**Conocimientos:** HTML, CSS, TypeScript, Preact (similar a React), Tailwind CSS.

**Primeras tareas:**
- Skeleton loading en Home
- Mejorar contraste WCAG AA
- Animaciones de transicion entre paginas
- Modo oscuro con tokens del design system
- Empty states con ilustraciones

---

## Backend

**Conocimientos:** TypeScript, Supabase (PostgreSQL), signals, PWA.

**Primeras tareas:**
- Mejorar sync offline
- Optimizar queries de busqueda
- Agregar validaciones en stores
- Documentar migraciones de Supabase

---

## Connectors

**Conocimientos:** TypeScript basico. No requiere experiencia avanzada.

**Primeras tareas:**
- Crear conector Cruz Roja Venezuela
- Crear conector FUNVISIS
- Ampliar registros en conectores existentes
- Conectar APIs reales cuando esten disponibles

Ver: [HOW_TO_CREATE_CONNECTOR.md](docs/connectors/HOW_TO_CREATE_CONNECTOR.md)

---

## AI

**Conocimientos:** TypeScript, NLP basico, clasificacion de texto.

**Primeras tareas:**
- Agregar nuevos intentos al classifier (donacion, voluntario)
- Mejorar extraccion de entidades (telefono, cedula)
- Soporte multilenguaje en respuestas
- Ajustar pesos del Humanitarian Brief

---

## Maps

**Conocimientos:** Leaflet, geolocation API, TypeScript.

**Primeras tareas:**
- Clusters de marcadores cercanos
- Filtros por tipo de entidad en MapView
- Heatmap de densidad de incidentes
- Ruta al hospital mas cercano

---

## QA

**Conocimientos:** Testing (Vitest o similar), TypeScript.

**Primeras tareas:**
- Tests para Evidence Engine
- Tests para person-matching
- Tests para humanitarian-brief
- GitHub Actions: CI basico

---

## Documentacion

**Conocimientos:** Markdown, espanol e ingles.

**Primeras tareas:**
- Traducir README a ingles
- Traducir onboarding/ a ingles
- Documentar migraciones de Supabase
- API reference de los motores
