# 🌎 Bienvenido a NODO

Gracias por estar aqui. Cada linea de codigo que escribas puede ayudar a salvar una vida.

NODO es una plataforma humanitaria Open Source cuya mision es conectar informacion de multiples organizaciones para ayudar a encontrar personas, coordinar ayuda y centralizar informacion verificada.

NODO no compite con otras plataformas humanitarias. Las conecta.

## 🧩 Elige como contribuir

Encuentra el camino que mejor se adapte a tu perfil en [CONTRIBUTOR_PATHS.md](CONTRIBUTOR_PATHS.md):

- 🎨 **Frontend** — UI, componentes, accesibilidad, design system
- ⚙️ **Backend** — Stores, logica, Supabase, offline sync
- 🔌 **Connectors** — Conectar nuevas plataformas a la Red NODO
- 🤖 **AI** — Motor Assist, clasificadores, extractores
- 🗺️ **Maps** — MapView, Leaflet, geolocation, rutas
- 🧪 **QA** — Tests unitarios, CI, verificacion cross-browser
- 📝 **Documentation** — Traducciones, guias, documentacion de APIs

## 🌿 Flujo de trabajo

```
develop → feature/mi-tarea → Pull Request → Review → Merge
```

1. Crear rama desde `develop`
2. Hacer cambios y commit
3. Push y crear Pull Request hacia `develop`
4. Esperar revision
5. Merge a `develop` → eventualmente a `main` (produccion)

Detalle completo: [DEVELOPMENT_WORKFLOW.md](DEVELOPMENT_WORKFLOW.md)
