# Bienvenido a NODO

Gracias por estar aqui. Cada contribucion a NODO puede ayudar a salvar una vida.

---

## Que es NODO

NODO es una plataforma de inteligencia humanitaria que conecta plataformas independientes de ayuda en Venezuela. Una sola busqueda consulta todas las fuentes, fusiona resultados, verifica evidencia y presenta informacion consolidada.

NODO no compite con otras plataformas humanitarias. Las conecta.

---

## Mision

Convertir informacion fragmentada en acciones coordinadas que salvan vidas.

---

## Como comenzar

```bash
git clone https://github.com/NODOPlatform/nodo.git
cd nodo
npm install
cp .env.example .env.local
npm run dev
```
