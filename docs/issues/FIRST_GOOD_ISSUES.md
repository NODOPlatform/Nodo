# Primeras tareas para nuevos colaboradores

Tareas pequenas ideales para empezar a contribuir a NODO.

---

## Conectores

1. **Nuevo conector: Cruz Roja Venezuela** — Integrar datos de Cruz Roja como nodo de la Red NODO.

2. **Nuevo conector: FUNVISIS** — Conectar datos sismicos del observatorio nacional.

3. **Nuevo conector: Proteccion Civil** — Integrar reportes oficiales de emergencia.

## UI y Frontend

4. **Mejorar contraste de colores** — Verificar y corregir ratios de contraste WCAG AA en botones y textos.

5. **Skeleton loading en Home** — Reemplazar spinners por skeletons en las cards del home.

6. **Animacion de transicion entre paginas** — Agregar transiciones suaves al navegar entre vistas.

7. **Mejorar el mapa** — Agregar clusters para agrupar marcadores cercanos en el MapView.

## Accesibilidad

8. **Atributos ARIA en formularios** — Agregar `aria-label`, `aria-required` y `aria-describedby` a todos los formularios.

9. **Navegacion por teclado** — Verificar que todas las acciones sean accesibles con Tab y Enter.

10. **Etiquetas alt en imagenes** — Revisar y agregar textos alt descriptivos en todas las imagenes.

## Traducciones

11. **Traducir UI a ingles** — Crear sistema de i18n basico y traducir las cadenas principales.

12. **Traducir onboarding a ingles** — Traducir los 5 documentos de `onboarding/` al ingles.

## Testing

13. **Tests unitarios para Evidence Engine** — Crear tests para `evidence-engine.ts` verificando niveles de evidencia.

14. **Tests unitarios para person-matching** — Crear tests para el algoritmo de coincidencias fuzzy.

## Documentacion

15. **Documentar las migraciones de Supabase** — Crear una guia explicando que hace cada migracion (001-012).

---

Para tomar una tarea: crear un Issue en GitHub, asignartelo y crear una rama `feature/` o `fix/`.
